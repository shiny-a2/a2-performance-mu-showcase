Project Status: Legacy showcase

## Current Direction

The newer repository explains the same portfolio area with better production context:

- request lifecycle and cache-safety boundaries;
- REST route pressure and fail-fast behavior;
- Action Scheduler maintenance;
- transient and autoload pressure;
- low-overhead instrumentation;
- operational tradeoffs and failure prevention.

## Why This Repo Remains Public

It preserves historical context while the public portfolio moves to a cleaner showcase structure. It should not be pinned once `a2-woocommerce-performance-lab` is pinned.

## Safety Policy

No production source, private URLs, credentials, real logs, customer/order data, or private business logic should be published here.
